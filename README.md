## What Costeo Adobe Does

Costeo Adobe provides an interactive way to prepare and examine Adobe Experience Cloud proposals. Its workflow combines use case discovery, licensing information, proposal refinement, and cost estimation in a single web application.

Teams can use it to structure solution conversations and assess proposal components more consistently. Relating business scenarios to licensing considerations and projected costs gives Adobe Experience Cloud planning a practical foundation.

## Workflow

Use Costeo Adobe in the following sequence:

1. Launch the application in a web browser.
2. Examine the available Adobe Experience Cloud use cases.
3. Choose the scenarios that apply to the proposal.
4. Read the licensing guidance connected with those selections.
5. Adjust the proposal according to the chosen requirements.
6. Refer to the cost estimation view for planning and comparison.
7. Recheck the assumptions whenever the proposal scope is modified.
